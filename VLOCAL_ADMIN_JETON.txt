Vlocal, jeton d'administration (généré le 2026-09-06)

Ce jeton ouvre https://www.vlocal.org/admin. Il n'existe qu'ici et dans votre
navigateur (localStorage) une fois saisi. Le serveur n'en stocke que l'empreinte
SHA-256 : une fuite de la base ne le révèle pas. Ne le collez nulle part ailleurs.

JETON :
U

Pour l'activer (une fois, console Supabase > SQL Editor, projet lvcqgfjyhjujqjgrckeg) :

  insert into app_config(key, value) values ('admin_token_sha256', 'd255c90d099410c2f72dcb2186ddb36989f2facca08607d2c8ca242d924bfa71')
  on conflict (key) do update set value = excluded.value;
  delete from app_config where key = 'admin_token';

Puis sur /admin : Déconnexion, puis saisir ce jeton.

Pour le changer plus tard : générer un nouveau jeton (64 caractères aléatoires),
calculer son SHA-256 (echo -n JETON | shasum -a 256) et rejouer l'insert ci-dessus.
